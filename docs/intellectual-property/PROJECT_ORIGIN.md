# Project origin

## Original project

FinSight began as a student-oriented personal finance concept for income, expense, budget, savings-goal, insight, and visual reporting workflows. The preserved source repository is [Dhruvi-tech/Finsight-Finance](https://github.com/Dhruvi-tech/Finsight-Finance). It was cloned and inspected on 2026-11-04; its visible history contains one initial commit and one README. No original implementation assets were found in the checkout. The referenced FinSight PDF was not available in the attachments supplied for this work.

## Enhanced project

The new repository `Dhruvi-tech/finsight-personal-finance` carries forward that source commit and adds a browser-based demonstration plus an API foundation. New work includes an original FinSight SVG mark, UI copy, a navy-and-soft-neutral interface, custom chart styling, responsive components, example demo interactions, deterministic financial calculations, and technical documentation.

The demo's ledger, budget and goal examples are synthetic. The app does not connect to a bank, provide investment advice, or transfer money. Original and enhanced work should be described separately in any application. This record documents the repository evidence available in the development workspace; it does not determine legal ownership.
