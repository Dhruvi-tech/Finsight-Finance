# Project origin

## Original project

FinSight began as a student-oriented personal finance concept for income, expense, budget, savings-goal, insight, and visual reporting workflows. The preserved source repository is [Dhruvi-tech/Finsight-Finance](https://github.com/Dhruvi-tech/Finsight-Finance). It was cloned and inspected on 2026-11-04; its visible history contains one initial commit and one README. No original implementation assets were found in the checkout. The referenced FinSight PDF was not available in the attachments supplied for this work.

## Enhanced project

The current repository `Dhruvi-tech/Finsight-Finance` carries forward that source commit and adds a browser-based finance interface plus an API foundation. New work includes an original FinSight SVG money mark, UI copy, a deep-green-and-soft-neutral interface, custom chart styling, responsive components, example demo interactions, deterministic financial calculations, and technical documentation.

The first interface iteration included synthetic ledger, budget, and goal examples; these were subsequently removed, and new accounts now start empty. The app does not connect to a bank, provide investment advice, or transfer money. Original and enhanced work should be described separately in any application. This record documents the repository evidence available in the development workspace; it does not determine legal ownership.
